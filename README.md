# tasker

A Todoist-style terminal task manager built with OpenTUI and React. Everything is
local: one JSON file at `~/.config/tasker/tasker.json`, no account, no network sync.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/gbsaito/tasker/main/install.sh | sh
```

Pin a version:

```sh
TASKER_VERSION=v2.0.0 curl -fsSL https://raw.githubusercontent.com/gbsaito/tasker/v2.0.0/install.sh | sh
```

## Uninstall

```sh
curl -fsSL https://raw.githubusercontent.com/gbsaito/tasker/main/uninstall.sh | sh
```
